# Diretrizes do Projeto — Os Melhores da Cidade

1. Sempre dê respostas e documentações em português do Brasil.
2. Em todas as alterações, correções, implementações e etc que fizer, atualize sempre o `CONTEXTO.md` com as mudanças realizadas, novas decisões técnicas, estrutura implementada e status atualizado do projeto.
3. Sempre ao final de qualquer entrega, implementação ou correção, forneça uma sugestão padronizada de mensagem de commit (Conventional Commits), pronta para copiar e colar, com título e descrição detalhada das mudanças.
4. Sempre ao final de uma implementação ou correção, envie uma lista com 5 opções de próximos passos (correções, implementações, melhorias ou validações) para o usuário escolher como continuar.
5. As portas dos serviços devem ser sempre preservadas sem conflito com outros projetos locais: Web (4101), NestJS API (4102), PostgreSQL (4103), Nginx (4100).
